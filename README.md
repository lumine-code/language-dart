# language-dart

Dart language support.

## Features

- **Grammars**: provides Tree-sitter grammars, built from [tree-sitter-dart](https://github.com/UserNobody14/tree-sitter-dart).
- **Syntax highlighting**: full tree-sitter grammar coverage for Dart files.
- **Folding**: folds blocks from the parse tree rather than by indentation.

## Installation

To install `language-dart` search for _language-dart_ in the Install pane of the Lumine settings or run `lumine --install lumine-code/language-dart`.

## Services

- **hyperlink.injection** (`^1.0.0`): consumed to highlight URLs inside Dart files as clickable links.
- **todo.injection** (`^1.0.0`): consumed to highlight `TODO`-style markers inside comments.
